# VIBRALYS - Feel The Vibe

Spotify Clone dibuat dengan Python Flet.

## Fitur
- Home dengan cover scroll
- Search lagu real-time
- Library liked songs
- Mini player + full player
- Lirik format .lrc
- Database lagu JSON
- Build APK Android

## Cara Jalankan
pip install -r requirements.txt
python main.py

## Edit Lagu
Buka assets/data/songs.json

## Build APK
flet build apk -v
File ada di build/apk/

## Struktur
VIBRALYS/
  assets/ -> gambar, json, lirik
  src/ -> kode utama
